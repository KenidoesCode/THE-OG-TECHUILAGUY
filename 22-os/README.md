# Techuilaguy OS

A from-first-principles operating-system prototype inside THE OG TECHUILAGUY.

Current target:
- x86-64 boot
- kernel entry
- serial console
- physical memory allocator
- kernel heap foundation
- interrupt descriptor table
- timer interrupt foundation
- scheduler/process model foundation
- syscall ABI foundation
- VFS foundation
- capability/security foundation
- userspace boundary

This is an engineering prototype, not yet a production OS.
